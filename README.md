# 备考台

备考台是运行在 Windows 本机的中文学习工作区。它按证书和科目管理教材、章节、练习、错题和考前计划。首次启动会创建一个独立的「项目管理基础」示例证书。

## 启动

需要 Node.js 24 或更高版本。在 PowerShell 中运行以下命令。如果交付目录已包含依赖和 `dist`，可以直接执行最后一条。

```powershell
Set-Location -LiteralPath 'F:\Code\MyWEB\cert-prep'
npm.cmd ci
npm.cmd run build
npm.cmd start
```

在浏览器打开 [备考台](http://127.0.0.1:4173)。终端会显示实际访问地址。按 `Ctrl+C` 停止服务。开发时使用 `npm.cmd run dev`，访问终端中 Vite 打印的本机地址。

## 启用 AI 和联网搜题

在项目目录运行 `Copy-Item -LiteralPath .env.example -Destination .env`，用文本编辑器打开 `.env` 后填写以下项目。保存并重启服务，页面中的「服务配置」会显示哪些项目已填写。

| 配置 | 填写内容 |
| --- | --- |
| `AI_BASE_URL` | 服务商提供的兼容 Chat Completions 基础地址，通常以 `/v1` 结尾。程序会追加 `/chat/completions`。 |
| `AI_MODEL` | 服务商的模型名称。选择可处理中文并返回 JSON 文本的模型。 |
| `AI_API_KEY` | 模型服务密钥。 |
| `TAVILY_API_KEY` | [Tavily](https://app.tavily.com/) 搜索密钥。 |

可独立配置两种服务。章节分析和出题只在你主动发起后发送当前章节文字。网络题草稿的 AI 整理会发送所选搜索结果的标题和摘要。Tavily 收到的是搜索关键词。教材上传、文字识别、已有练习和学习计划在本机执行。

## 使用流程

1. 选择示例证书，或新建自己的证书并填写考试日期。新证书会自动创建默认科目，只有一个科目时资料会自动归入。需要分科时，可在资料库添加科目。
2. 在资料库选择「上传原课本」或「上传补充资料」。已上传的教材可在资料详情设为原课本。支持文字 PDF、扫描 PDF、DOCX、TXT、PNG 或 JPEG。单个文件上限为 500 MB，PDF 上限为 1000 页。默认尝试识别缺少可用文字层的 PDF 页。文字层异常时，可在上传时勾选「对整份 PDF 使用 OCR」。扫描 PDF 会根据可用 CPU 和内存同时识别多页，完成后按原页码排序。中文 OCR 以简体中文印刷文字为主，识别后可逐片段校对。
3. PDF 会按版面整理段落和换行，清理边角推广水印，并为识别到的公式、插图和表格显示原页局部图。PDF 和图片识别后也会清理页边的页码和可明确修正的括号。原文件和页码定位仍可在资料详情查看，并可手动校对原文片段与建议章节。PDF 有正文章节书签时按书签分章，并跳过封面、目录等正文前的页；可通过原文件查看这些页面。其他资料自动分章时跳过导言、前言等开篇内容。能识别到的字体颜色、高亮和下划线会显示在原文片段与章节原文中。资料详情支持删除原文片段；相关章节的分析需要重新生成。学习清单优先使用原课本，同一科目的同名补充章节可在「按资料查看」中找到。学习计划按清单生成。进入章节可修改标题、范围和预计时长。PDF 引用可打开原页。DOCX 和 TXT 通过原文片段定位。
4. 在章节详情分析原文、生成练习题，或去联网搜题。网络题先保存为草稿，在章节页核对题干、答案、解析和链接后点「审核并收录」。已有出处时也可手动录入网络题。
5. 学完一章后点「标记学完」，再完成章节练习。错题可按科目和章节重练。复习时答对会标记为已掌握，作答历史仍可查看。
6. 在学习计划选择可学习日和每日分钟数，生成或补排任务。计划按本机日期计算，截止到考试前一天。改期会重新安排待完成任务并保留完成记录。导入新章节或调整章节时长后，点「重新排程 / 补排」更新计划。

## 数据与验证

- `data/study.sqlite` 保存学习记录，`data/uploads` 保存原文件。备份前停止服务，再复制整个 `data` 目录。`.env` 单独保存，避免把密钥放进分享的备份。
- `npm.cmd test` 使用临时数据库和测试资料，覆盖 OCR、导入、评分、错题、重新排程及服务异常。测试对 AI 和 Tavily 使用模拟返回。本机环回地址需能访问，以便运行接口测试。
- 初次导入或识别扫描件耗时可能较长。上传时可取消。可在资料详情删除资料，关联章节及学习记录会一起删除。已经上传的资料可取消后台识别，随后用原文件重试。后台任务可在资料或章节页查看。对加密或超出上限的 PDF，请先在原工具中另存或拆分。
